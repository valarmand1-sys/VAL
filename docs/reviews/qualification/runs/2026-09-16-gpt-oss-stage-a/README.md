This directory holds the evidence for the owner's reading. **No verdict is declared here.** GPT-OSS remains `NOT_ADMITTED`, candidate/evaluation only; Sol remains the production Partner.

- `benchmark.json` — the twelve scored tasks, two per capability area, with every mechanical check, **frozen at commit `60b65b7` before any prompt was sent**. No prompt was modified after an answer was seen; no task was substituted.
- `harness_stage_a.py` — runs the tasks through the real candidate path on the scratch store `val_test` (active persona v1.8 whole, the Core record-state and capability-state envelopes, retained history, the exact local context preflight, the OpenAI-compatible HTTP inference path; no classification, strip or blind call; no cloud provider), after a read-only verification that exactly one `openai/gpt-oss-20b` is resident at 32,768 (it STOPs otherwise). - `observations-engineer.json` — the engineer's read of each answer against the frozen notes: constraints / invention / omission / contradiction / correction-preserved, with a note. A human reading; never the model grading itself, never a cloud judge.
- `packet_stage_a.py` → **`review-packet.md` — the owner review packet**: per task the prompt sequence, GPT-OSS's exact visible response, the objective observations, and the latency/token summary; an aggregate mechanical summary at the end.
